# Spring Boot Web App: Detalles de Usuario

## Descripción

Este proyecto Spring Boot es una demostración fundamental de una aplicación web que muestra información de usuario.  Está diseñado para servir como punto de partida o referencia para desarrolladores que buscan comprender la integración de Spring MVC, Thymeleaf y Spring Boot Devtools.

## Características

* **Spring MVC:** Manejo de solicitudes web y enrutamiento mediante el patrón Modelo-Vista-Controlador.
* **Thymeleaf:** Generación dinámica de HTML a partir de datos del servidor.
* **Spring Boot Devtools:** Habilitación de recarga automática y otras herramientas de desarrollo para un flujo de trabajo eficiente.
* **Java 21:** Construido con la última versión de Java para aprovechar las nuevas características y mejoras de rendimiento.
* **Maven:** Gestión de dependencias y construcción del proyecto.

## Requisitos Previos

Asegúrate de tener instalado lo siguiente:

* **Java Development Kit (JDK) 21:** Puedes verificar tu versión con `java --version`.
* **Visual Studio Code (u otro IDE de tu elección):** Recomendamos instalar las siguientes extensiones para una mejor experiencia de desarrollo Spring Boot:
    * Spring Boot Extension Pack (VMware)
    * Extension Pack for Java (Microsoft)
* **Maven:** Normalmente se instala con Spring Tool Suite o se puede instalar por separado.

## Configuración e Instalación

1.  **Clonar el repositorio:** `git clone <URL_DEL_REPOSITORIO>`
2.  **Importar el proyecto en tu IDE:** En Visual Studio Code, puedes abrir la carpeta del proyecto.
3.  **Construir el proyecto:** Utiliza Maven para construir el proyecto.  Puedes hacerlo desde la línea de comandos con `./mvnw clean install` (en Linux/macOS) o `mvnw clean install` (en Windows), o a través de tu IDE.
4.  **Ejecutar la aplicación:** Ejecuta la clase principal `com.informaticadsy.spring.app1.springboot_aplications.SpringbootAplicationsApplication` desde tu IDE o utilizando el comando `./mvnw spring-boot:run` (en Linux/macOS) o `mvnw spring-boot:run` (en Windows).
